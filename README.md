### 国内企業分析プラットフォーム
QFINDRは国内企業分析のための様々な情報提供、企業検索や評価レポートの作成、業界実績に裏付けされた信用リスク分析や企業評価技術に基づいた各種指標データを提供するクラウドサービスです。

- 国内約100万社超の企業データを収録し、多様な視点での企業評価情報を提供
- 企業属性情報および財務情報両面からの独自アルゴリズムによる企業検索
- 企業分析結果を集約した詳細な個社レポート
- 信用リスク分析ノウハウに基づくリスク評価モデルによる取引先与信管理支援
- 独自AIモデルに基づく「成長志向評価格付」
- 企業価値評価に必要な各種パラメータ算出
